# 山河志最终性能验证：固定版本 10 轮交错对照

本轮最终版已修复上轮退化：同场比较的四组首图耗时、四组首页全量就绪耗时，中位数均优于优化前原版及上轮已发布版。首图耗时相对原版减少 **16.83%–19.01%**，相对上轮发布版减少 **25.23%–47.73%**。没有达到“相对原版全面再快 20%”；缓存后高 DPR 中位数 **83.80 ms**，仍高于 **80 ms**，如实保留。

最终代码已冻结，不依据本组结果再替换变体、丢弃样本或改变测量口径。

点选采用 CDP 实际鼠标点击珠穆朗玛峰搜索结果，记录面板 DOM 更新及其后两帧的反馈时间；包含输入事件时间戳，未将“相机飞行完成”或“高清影像完成”混入反馈指标。最终版 20 次点选均低于 40 ms。

首页完整就绪后，同时旋转 25°、缩放 +0.2，持续 2 秒：DPR1 render 回调 **126.25 fps**，p95 间隔 **9.10 ms**；DPR2 **124.22 fps**，p95 **9.50 ms**。每组仅一个运动样本；这是 Headless 渲染回调吞吐量，不能当作物理屏幕帧率或所有 PC 的保证。

所有最终版导航样本均验证：81 张完整卡片（末项麦积山）、81 个地点源、9 个区域名称实际渲染、84 个山河地貌、初始 27 块 z4 卫星纹理、地形夸张系数 1.5、原生 DPR1/DPR2 画布分别 1496×900 / 2992×1800。没有降低本轮画布清晰度或替换影像源。

另见 [最终功能回归](regression-cards-report.md)：19 项通过；首屏 5 张原有节点与焦点保留，其余卡片追加为 81 张，早期切换/下一张/Tab 到末项均通过。[图像回归](regression-images-report.md)抽检 6 张 satellite/relief JPEG，两种解码路径完整 RGBA 逐通道差异为 0，且原文件 SHA256 相同；DEM 继续保留编码字节。

## 目标逐项判断

| 目标 | 本次证据与结论 |
|---|---|
| 首次地图可见并可操作 ≤640 ms | 本机本地首页冷导航全部通过；最终版实测最大 105.80 ms。未等同于公网或全新系统首次启动保证。 |
| 缓存后打开 ≤80 ms | **未全面达标**。DPR1 median 76.60、p90 80.20、max 82.10，8/10 次 ≤80；DPR2 median 83.80、p90 85.90、max 86.50，仅 2/10 次 ≤80。 |
| 点选反馈 ≤40 ms | 已测实际点选全部通过，最终版最大 21.70 ms。 |
| 首批实景建筑可见 ≤640 ms | **本组未测**，不能宣称达标。 |
| 当前视野高清细节补齐 ≤800 ms | 仅本地首页“地形、山河、标签全量就绪”全部通过，最大 333.40 ms；具体地点高清细节和实景模型未测。 |
| 普通地图 ≥100 fps | 已测 Headless render 回调样本超过目标；**物理显示帧率未验证**。 |
| 复杂实景 ≥75 fps | **本组未测**，不能宣称达标。 |
| 相对原版整体再快 20% | **未全面达标**；首图中位耗时减少 16.83%–19.01%，首页全量中位耗时减少 4.50%–9.63%。 |

## 环境与边界

- Apple M5，10 CPU 核，16 GiB 内存；HeadlessChrome 145.0.7632.6；ANGLE Metal / Apple M5，WebGL 2。未启用 CPU 降速。
- 固定 1496×900 PC 视口、DPR1 与 DPR2，mobile=false；没有 iPad 或手机测试。
- 同一个浏览器进程依次测试 original / published / cards，轮次间反转顺序；每次冷导航立即跟随真实 Page.reload。总计 **120 个实测导航、6 个独立暖机、60 次点选、6 个运动样本**，全部保留。
- 冷导航先进入 about:blank，再清 HTTP 缓存和对应 origin 存储；每个版本使用独立端口。缓存重载验证 navigation.type=reload 与 pageshow.persisted=false，排除 BFCache。GPU、shader、操作系统及潜在图像解码缓存共享且未清；没有隔离其它桌面应用负载。不能将重复冷导航冒充全新机器首次启动。
- 所有版本使用同一个静态服务处理器、同样的缓存语义；本地回环网络，无限速。浏览器非本地请求被屏蔽，故结果不包含 GitHub Pages 网络时延、跨境网络、第三方影像服务或远程实景模型下载。
- 产品 Runtime 异常 **0**。工具层异常 **1**：离开详情页时 everest.jpg 请求取消引起 Fetch InvalidInterceptionId；原样记录在 JSON，未冒充产品异常，也未删除对应样本。
