# 山河志 · ATLAS OF CHINA

一部可以探索的中国地理图鉴。真实三维地形、卫星影像、地理叙事与实景摄影，呈现中国的自然与人文。

## 运行

需要 Node.js 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。正式构建与预览：

```bash
npm test
npm run build
npm run preview
```

`dist/` 是完整静态网站，可部署到支持 HTTPS 的静态托管平台；不需要数据库、后端服务或 API Key。项目使用站点根路径，部署时应将 `dist/` 内容放在域名根目录。不能直接双击 HTML 运行，需要 HTTP 服务。

## 探索方式

- 拖动平移，滚轮缩放，右键拖动旋转和倾斜；手机双指操作。
- 点击地图标记或照片卡片，镜头飞向真实地点，展开地理与人文介绍。
- 地点详情以图文手记呈现：封面、事实卡、两段专属章节、第二幅地点影像及“在这里，看见什么”观察手记。点击图片查看大图，支持左右按钮、方向键切换，`Esc` 关闭后回到原阅读位置。
- 手机点击“展开阅读”查看完整图文，再“收起阅读”继续探索地图；展开阅读或查看大图时自动暂停漫游。切换地点重置阅读位置。
- 自然 / 人文筛选，支持中文、英文、区域与标签搜索；`⌘/Ctrl + K` 或 `/` 打开搜索。
- 图层面板切换卫星影像与地形晕渲，叠加省级边界；山系与水系默认开启，可分别隐藏。
- 暖金虚线呈现山系总体走向，冷青线呈现主要水系，黄河以金色区分。全国视野先显示主干，区域放大后逐步显示支流与更多山系。
- 点击山脉、河流的线条或中文名称，高亮选中对象、适配其视野，并展开地理介绍、所属水系或总体走向、来源与精度说明。图层面板可按名称定位全部 **84 项**山系和河流。
- `3D` 切换三维 / 平面，指南针恢复正北，房屋按钮回到中国全景。
- 山河漫游每 11 秒前往下一处，支持暂停、继续与跳转；12 个专题组织不同的地理叙事；首页默认精选 12 站，约 2 分钟。
- 地点链接支持 `/#everest` 等直接访问。`Esc` 关闭对话框或返回全景。

## 内容与资料

收录 **81 个代表坐标**，覆盖 **34 个省级行政区**，包含五岳与名山、雪山高原、江河峡谷、湖泊湿地、沙漠海岸，以及古城、宫殿、石窟、园林与文化景观。新增内容如泰山、华山、黄河壶口、雅鲁藏布大峡谷、九寨沟、长白山、巴丹吉林、太鲁阁、兵马俑、布达拉宫、莫高窟、龙门石窟、苏州园林、福建土楼和红河哈尼梯田。

**山河目录**提供八类主题、34 地区和关键词的组合筛选；地图标记随缩放和空间避让逐步呈现，选中地点始终保留。目录和搜索可找到所有地点。

**12 条主题旅程**：三级阶梯、五岳名山、雪山高原、江河峡谷、湖泊湿地、沙漠红层、山林生态、海岸岛屿、古都中轴、石窟与造像、古城都市、园林乡土。每处地点至少纳入一条路线，专题卡片显示站数与预计时间。

**24 条山系与 60 条河流 / 河段**构成地图的地理骨架。山系包含喜马拉雅、昆仑、天山、秦岭、太行等；水系包含长江、黄河、黑龙江、松花江、辽河、海河、淮河、珠江、闽江、澜沧江、怒江、雅鲁藏布江与塔里木河等代表性水系。长江、金沙江、通天河、沱沱河及珠江水系的西江、浔江、黔江、红水河、南盘江保留各自河段名称。图层适用于全国与区域认知，三维和平面模式都可探索；放大至 zoom 7.3–8.5 时线条与标签逐渐隐去，转而观察影像与真实地形。

内容位于 `src/content.js`、`src/content-nature.js` 与 `src/content-culture.js`；路线与分类见 `src/journeys.js`。摄影均为真实地点的 Wikimedia Commons 作品；作者、原作、公开许可或公有领域说明与图片缩放压缩说明保存在 `public/data/photo-sources.json`，站内说明及地点详情提供来源和许可链接。字体为 OFL 授权的本地 Noto Serif SC 中文子集，避免依赖在线字体。

`src/place-stories.js` 为全部 81 个地点提供 162 个专属章节标题及逐处观察手记，连接地理成因、自然生态与人文空间。每处新增一幅不同于封面的地点影像，共 81 幅、约 14.25 MB；最长边不超过 1200 像素，随详情按需加载。来源清单为 `public/data/detail-photos-nature.json` 与 `public/data/detail-photos-culture.json`，每幅均附中文图注、替代文本、作者、许可与原作链接，可在图注下展开或在“关于山河志”集中查阅。莫高窟采用一幅壁画忠实复制图，贺兰山及大足的补图为展陈照片，均在图注明确说明；不将复制图或展陈冒充现场景观。

## 地图精度与网络

- MapLibre GL JS 6.15 渲染三维地形，影像来自 Esri World Imagery / World Shaded Relief，高程来自 Mapzen / AWS Terrain Tiles。
- 三维起伏为真实高程栅格驱动；垂直起伏放大 **1.5 倍** 以便观察。卫星影像拍摄时间、分辨率及 DEM 精度因地区而异。
- DataV GeoAtlas 原始全国轮廓和省级边界包含 34 个省级行政区，保留台港澳、海南及南海原始几何。边界为概略地理数据，近景自动隐去，不作为测绘、法律或导航依据。
- 叙事地点采用 WGS84 代表位置，并不等同于照片拍摄机位、景区入口或景区范围。桂林点位依据照片公开 GPS；珠峰使用峰顶位置；金山岭与月牙泉已与照片主题校正。
- 珠峰 **8848.86 米** 是 2020 年共同公布的雪面高程，独立于栅格 DEM 采样结果。青海湖湖面海拔用约数，并说明随水位变化。
- 水系来自 [Natural Earth 1:1000万河流与湖泊中心线](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-rivers-lake-centerlines/)，依据其[公有领域条款](https://www.naturalearthdata.com/about/terms-of-use/)使用。60 项为代表性选择，并非完整中国河网；保留源数据原始顶点与分段，不补绘湖区、河口或断段，也不据此推算实测河长。部分跨境河流保留境外延续；岷江、沱沱河、塔里木河等存在未收录河段，长江下游与部分河口也未完整表示，逐条说明见 `public/data/rivers.geojson`。中心线不代表精确河岸、当前河道或航道。
- 山系来自公开地理资料核对后的**手工概化走向轴线**，未从 DEM 提取山脊，也未采集 GPS 轨迹；暖金虚线不代表精确山脊、山系边界或登山路线。24 项的逐条资料链接、方向与精度说明见 `public/data/mountains.geojson`；参考资料用于核对山系名称和区域背景，并非轴线节点坐标来源。
- 山系与水系的三级层级仅用于控制展示密度，不是官方山系等级或水文河流级序。世界遗产条目链接及政府机构链接可供进一步查阅，部分机构主页不是逐条论断的原文出处。
- 已本地缓存全球 z0–4、亚洲范围（55°E–180°E，20°S–70°N）z5 的三类瓦片，共 **1,419 张、约 42.79 MB**。首屏、字体、摄影、边界和内容可由本地服务器直接提供；进一步放大需要连接在线瓦片服务。
- 需要支持 WebGL 的现代浏览器。正式公开部署前，应根据实际托管环境检查外部瓦片连通性和相应服务使用条款。

地图来源与缓存范围：`public/data/map-sources.json`。重新获取瓦片可运行 `node scripts/cache-map.mjs`；该脚本使用 `curl`，并保留已存在的缓存。

重建水系可运行 `python3 scripts/build-rivers.py`，或使用 `--source /path/to/ne_10m_rivers_lake_centerlines.geojson` 指定已下载的原始数据。生成结果保留源要素编号、选用组件和原始文件 SHA256，便于追溯；脚本只使用 Python 标准库。上游数据更新后，应重新核对名称、汇流点和显示范围。

## 验证

`npm test` 包含 **14 项数据检查**：81 地点坐标与唯一性、34 地区与八类主题的内容完整性、默认漫游时长与 12 条路线、章节覆盖、摄影与授权；全部地点的图文标题和观察手记覆盖、新增影像与封面来源不同、图注与许可、本地 JPEG 和文件字节一致；行政区边界及台港澳海南轮廓；山系资料、示意精度与区域走向；水系来源、许可、跨境范围、主要水系与河段名称，以及宜宾汇流点处金沙江和长江的名称衔接。

浏览器验证记录按轮次保存在 `VALIDATION.md`；既有记录保留各轮实际检查范围，本轮结果以新增记录为准。数据测试不替代浏览器中的三维渲染、交互和视觉检查。本项目为独立科普与设计作品，与星球研究所无关联。
